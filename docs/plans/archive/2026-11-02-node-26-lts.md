# Node 26 LTS – plan

**Mål:** CI, bygg og lokal utvikling skal kjøre på Node 26.13.0, og #530 skal lukkes. Dependabot skal fortsatt fungere.

**Spec:** [docs/designs/archive/2026-11-02-node-26-lts.md](../../designs/archive/2026-11-02-node-26-lts.md)

**Kjøring:** inline i én worktree.
- Node 26: `/home/asbjorn/.nvm/versions/node/v26.13.0/bin` (installert 2026-11-02, npm 11.20.0)
- Node 24 for gulvsjekken: `/home/asbjorn/.nvm/versions/node/v24.22.1/bin`

## Avgrensninger

Følgende er ikke med:
- Lambda-runtime i AWS. Merk: zip-pakken bygges i `update-lambda` under Node 26
  (`npm ci --omit=dev`), mens AWS kjører `nodejs24.x`. Det er trygt fordi pakken
  bare er ren JS uten native moduler.
- avhengighetsoppgraderinger
- endringer i workflows
- endringer i Node Version Watch

Se spec-en for begrunnelsen.

## Steg

### 1. Worktree

1. Opprett worktree `node-26` med `EnterWorktree`.
2. Kopier spec og plan inn i worktreet.
3. Kjør `bash scripts/setup-worktree.sh`.

### 2. Endringer (3 filer)

1. **`.nvmrc`:** sett innholdet til `26.13.0`. Ingen `v`, med linjeskift til slutt.
2. **`package.json`:** sett `engines.node` til `">=24.15.0 <27.0.0"`.
3. **`package-lock.json`:** synk rot-oppføringens `engines` med
   `npm install --package-lock-only --ignore-scripts` under Node 26.
4. Kontroller lockfila:
   - `git diff package-lock.json` skal bare vise endringer i rot-blokken `packages[""].engines`.
   - Viser diffen endrede versjoner av avhengigheter, stopp og finn ut hvorfor.

### 3. Verifisering under Node 26

Kjør med `PATH=/home/asbjorn/.nvm/versions/node/v26.13.0/bin:$PATH`. Hver kommando skal gi exit 0.

| Kommando | Forventet |
|---|---|
| `node -v` | `v26.13.0` |
| `npm ci` | ingen `EBADENGINE`, exit 0 |
| `npm run lint` | 0 errors |
| `npm run check` | 0 errors (`astro check`, samme som CI-jobben `type-check`) |
| `npm test` + `npm run coverage:check` | alle tester grønne (i dag 1911), ≥ 80 % branch per fil |
| `bash .claude/skills/_shared/run-e2e.sh` | alle grønne (i dag 96) |
| `npm run build:ci` | exit 0 |
| `npm run sync` og deretter `npm run build` | ekte Drive/Sheets-sync og bygg fungerer på 26 (googleapis, sharp) |
| `npm audit --audit-level=critical` | 0 kritiske |

Testene for Lambda (`lambda/kontakt-form-handler/__tests__`) kjøres av vitest fra
rot-katalogen. Standard-reporteren viser ikke filnavn når alt er grønt, så bekreft
med `npx vitest --run lambda/` (forventet: 1 fil, 24 tester, alle grønne).

`setup-worktree.sh` kopierer ikke `src/content/tjenester/` og `meldinger/`. Derfor
bygger `build:ci` i worktreet 9 sider med advarsler om tomme samlinger, ikke 12. Det
er ikke en Node 26-feil. Den ekte `npm run sync` + `npm run build` henter innholdet
og skal gi 12 sider.

Hele kvalitetsporten (`/quality-gate`) kjøres via `/commit`. Tabellen over er det
porten skal vise, pluss `astro check` og ekte sync, som porten ikke dekker.

### 4. Gulvsjekk under Node 24

Kjør med `PATH=/home/asbjorn/.nvm/versions/node/v24.22.1/bin:$PATH`:
- `npm ci --ignore-scripts` gir exit 0 uten `EBADENGINE`.

Det beviser at Dependabots image, som bruker Node 24, fortsatt kan installere. Kjør
`npm ci` under 26 igjen etterpå, så `node_modules` er tilbake på 26.

### 5. Commit, review, ship

1. Kjør `/commit`. Meldingen er:
   `chore: Node 26 LTS (26.13.0) — taket i engines løftes til <27, gulvet blir på 24 for Dependabot`.
   Brødteksten skal inneholde `Closes #530`. Den skal stå i denne første commiten.
   PR-teksten fra `auto-pr.yml` inneholder ikke `Closes`, så commit-meldingen er
   eneste kilde.
2. Kjør `review-loop`. Diffen er liten, så én reviewer er nok.
3. Arkiver TODO-oppgaven, spec og plan før den siste `/commit`.
4. Spør om push-godkjenning, deretter `git review`.

### 6. Etter merge (jeg gjør det selv)

1. CI/CD på main skal være grønn. Loggen skal vise `Resolved .nvmrc as 26.13.0`, og siden skal svare 200.
2. #530 skal være lukket. Hvis ikke, lukk den med en kommentar som peker på commiten.
3. Kjør `gh workflow run "Node Version Watch"`. Den skal være grønn og ikke åpne noen ny issue.
4. Kjør `gh workflow run "Scheduled Security Audit"`. Den skal være grønn på 26, siden den også bruker `.nvmrc`.
5. Bytt lokal Node i hovedtreet til 26:
   - Kjør `nvm alias default 26.13.0`.
   - Kjør `npm ci` under 26, siden `node_modules` der ble installert under 24.
6. Sjekk den første ukentlige Dependabot-kjøringen for `/` etter merge. Den skal ikke ha `EBADENGINE`. Den kan ikke trigges manuelt, så den sjekkes ved neste helsesjekk.

## Definition of done

- Akseptansekriteriene 1–8 i spec-en er oppfylt.
- Kvitteringen fra `/commit` har bare ✅.

## Risiko

| Risiko | Tiltak |
|---|---|
| En avhengighet feiler på 26 | Stopp i steg 3. Rapporter pakke og feil, og spør om vi skal vente eller omgå. Ingen stille workaround. |
| `npm install --package-lock-only` endrer mer enn `engines` | Stopp og forklar (steg 2.4). |
| Playwright-nettleserne må installeres på nytt under 26 | `run-e2e.sh` bruker de samme nettleserne. Ved feil kjøres `npx playwright install` på nytt. |
| Lokalt verktøy (skills, minne) peker på v24.22.1-stien | Ingen skills har den stien hardkodet (sjekket med grep). Minnet nevner den ikke. |
